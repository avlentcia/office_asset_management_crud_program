# Python CRUD Application for Office Asset Management

A comprehensive Python application for managing office asset data with Create, Read, Update, and Delete (CRUD) operations.

## Business Understanding

This project caters to the business in every industry, specifically addressing the need to manage office asset data efficiently. The system will help staff monitor office assets in real-time and minimize the risk of lost items.

**Benefits:**

* Improved data accuracy and consistency
* Streamlined data management processes
* Improved asset tracking and monitoring
* Reduced risk of asset loss
* Improved work efficiency and productivity by elimination manual administrative process

**Target Users:**

This application is designed for administrative staff officer within the organization to facilitate their administrative and registration task related to office asset management.

## Features

* **Create:**
    * Add new office asset entries with essential details like employee ID, employee name and office asset name.
* **Read:**
    * Search and retrieve specific office asset records by applying filters based on the asset borrowing status, employee ID or asset name.
    * Display comprehensive information for each office asset in a user-friendly format.
* **Update:**
    * Modify existing office asset data to reflect changes in the asset borrowing status.
    * Provide clear confirmation or error messages based on update success or failure.
* **Delete:**
    * Allow for the removal of unwanted office asset borrowing request records with appropriate authorization checks.
 
## Installation

1. **Prerequisites:**
    * Python version 3.13 or later

2. **Installation:**
    ```bash
    git clone https://github.com/avlentcia/office_asset_management_crud_program.git
    cd office_asset_management_crud_program
    ```

## Usage

1. **Run the application:**
    ```bash
    python main.py
    ```

2. **CRUD Operations:**
    * **Create:** Add a new office asset borrowing request, for example, an employee in a office want to borrow an asset, so the administation staff will add the new request into system, providing details like employee ID, employee name and asset name.
    * **Read:** Search and retrieve asset information by status, ID, or asset name.
    * **Update:** Modify the status of asset details, such as updating their request status into borrowed or returned.
    * **Delete:** Remove a office asset request record from the system.
